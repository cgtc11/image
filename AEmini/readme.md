# AEmini 機能説明書

AEminiはブラウザ（Chrome推奨）で動作する軽量タイムライン動画エディタです。  
After Effectsとの双方向JSON連携（Mini2AE.jsx）に対応しています。

## ツールバー

ツールバーは左から順に以下の順序で並んでいます。

### ファイル操作（左端）

|ボタン|説明|
|-|-|
|📂 読込|保存済みJSONプロジェクトを読み込む|
|💾 保存|プロジェクトをJSONとして保存|
|💾 収集保存|プロジェクトJSONと全素材を指定フォルダにまとめて保存|

### 再生

|ボタン|操作|ショートカット|
|-|-|-|
|▶ 再生|再生・停止切り替え|Space|
|■|停止して先頭に戻る|—|
|◀\||1コマ戻る|← または ,|
|\|▶|1コマ進む|→ または .|

### 設定

|項目|説明|
|-|-|
|解像度|1920×1080・1280×720・カスタムを選択。幅×高さを直接入力も可|
|FPS|フレームレートを設定（デフォルト24）|
|尺(秒)|アクティブなコンポの長さ|
|F ボタン|タイムライン表示をフレーム数(F)と秒(S)で切り替え|

### ツール

|ボタン|説明|
|-|-|
|✏ ペン|ペン描画モードON/OFF。ON時プレビュー背景が赤くなる|
|色ピッカー|ペンの色を選択|
|サイズスライダー|ペンのサイズ（1〜40）|
|T+|テキストレイヤーを新規作成|
|◆M|現在位置にマーカーを追加 (Mキーでも可)|

### 表示モード（右端）

|ボタン|説明|
|-|-|
|通常|通常モード（全パネル表示）。クリックで簡易モードに切り替え|
|簡易|簡易モード（ツールバー・プレビュー・ルーラーのみ）。クリックで通常モードに戻る|

## 素材パネル（左側）

### ファイルのドラッグ＆ドロップ

ブラウザの画面上にファイルをドロップすると素材パネルに追加されます。

* 画像（PNG・JPG等）、動画（MP4等）、音声（MP3・WAV等）に対応
* 複数ファイルをまとめてドロップ可能
* 同じプレフィックス・同じ拡張子のグループは自動的に\*\*連番素材（SEQ）\*\*として読み込まれる

**空コンポへの1素材ドロップ時の特別動作：**  
アクティブなコンポが空の状態で素材を1つだけドロップすると、以下が自動で行われます。

* コンポのサイズを素材の解像度に合わせて調整
* コンポの尺を素材の長さに合わせて調整（動画・音声・連番は実尺、静止画は10秒）
* 先頭レイヤーに自動配置
* タイムラインのズームを素材の長さに合わせて自動フィット

### 素材の追加（ボタン）

|ボタン|説明|
|-|-|
|単/連番素材を追加|PNG・JPG等の静止画、または連番画像（ファイル名順に複数選択）を追加|
|MP4動画を追加|動画ファイルを追加|
|音楽を追加|MP3・WAV等の音声ファイルを追加|
|平面を作成|単色の平面素材を作成。色・名前を指定|

### 素材の種類とバッジ色

|バッジ|種類|
|-|-|
|SEQ|連番画像|
|IMG|静止画|
|MP4|動画|
|AUDIO|音声|
|SOLID|平面（単色）|
|TEXT|テキスト|
|COMP|コンポジション|
|??|リンク切れ（赤）→「リンク」ボタンで再指定|

### 素材の操作

* **クリック** → プロパティパネルに情報表示
* **ドラッグ** → タイムラインのレイヤーにドロップして配置
* **✕** → 素材を削除
* **✏** → 名前を変更

### フォルダ管理

* **📁+** → 新規フォルダを作成
* **▼/▶** → フォルダを開閉
* **ドラッグ** → 素材やフォルダをフォルダ内に移動
* フォルダ外の空きにドロップ → フォルダから出す
* フォルダの中にフォルダを入れることも可能

### コンポジション

* コンポをクリック → そのコンポを開く
* コンポをタイムラインにドロップ → ネストコンポとして配置
* コンポのプロパティに「MP4書き出し」「連番書き出し」ボタンあり

## プレビューエリア（中央上）

### 表示倍率

|ボタン|説明|
|-|-|
|Fit|プレビューエリアのサイズに合わせて自動フィット|
|25% / 50% / 100%|固定倍率で表示|

### プレビューでの操作

* クリップを選択した状態でプレビュー上でドラッグ → **移動**
* 四隅のハンドルをドラッグ → **スケール変更**（回転中でも正確に掴める）
* Shift+コーナードラッグ → **等倍スケール変更**
* プレビューとタイムラインの境界線をドラッグ → **プレビューエリアのサイズ変更**

## タイムライン

### 起動時のデフォルト構成

新規コンポは **V2・V1・A1** の3段レイヤーで始まります。  
レイヤーは必要に応じて「+映像」「+音声」ボタンで追加できます。

### コンポタブ

* タブをクリック → コンポを切り替え
* タブをドラッグ → コンポの順序を変更
* **+** → 新規コンポを追加
* タブの **✕** → コンポを削除（2つ以上ある場合）

### レイヤー操作

|操作|説明|
|-|-|
|+映像|映像レイヤーを1つ追加|
|+音声|音声トラックを1つ追加|
|● / ⊘ アイコン|レイヤーの表示/非表示を切り替え|
|✏ アイコン|レイヤー名を変更|
|✕ アイコン|レイヤーを削除|
|ドラッグ（レイヤー名）|レイヤーの順序を変更|

### ズーム

「ズーム」の文字（点線アンダーライン）をクリックすると、コンポ全体がタイムラインの表示幅にぴったり収まるよう自動調整されます。  
スライダーで手動調整も可能です。  
簡易モード時はルーラー右端に「ズーム」ボタンが表示されます。

### クリップ操作

|操作|説明|
|-|-|
|クリップをクリック|クリップを選択 → プロパティ表示|
|クリップをドラッグ|クリップを移動|
|Shift+ドラッグ|他のクリップにスナップしながら移動|
|右端/左端をドラッグ|クリップの長さをトリミング|
|Shift+右端/左端|タイムリマップ（速度変更）|
|Ctrl+C|選択クリップをコピー|
|Ctrl+V|プレイヘッド位置にペースト|
|Delete / Backspace|選択クリップを削除|
|Ctrl+Shift+D|プレイヘッド位置でクリップを分割|

### ルーラー

* クリック or ドラッグ → プレイヘッドを移動（シーク）

### マーカー

* **Mキー** または **◆Mボタン** → 現在位置にマーカーを追加（ラベル入力可）
* マーカーをクリック → その位置にジャンプ
* マーカーを右クリック → 削除
* 色はマーカーごとに自動設定

## プロパティパネル（右側）

### クリップ未選択時

素材パネルの素材をクリックすると、その素材の情報（種類・サイズ・尺など）が表示されます。

### クリップ選択時のレイアウト順

#### ① 合成モード（最上部・常に表示）

通常・スクリーン・加算・乗算・オーバーレイ・反転（差分）から選択。

#### ② テキスト内容（テキストクリップのみ）

テキスト本文・フォントサイズ・色・整列・フォント・太字/斜体・縁取りを変更できます。

#### ③ 配置

|項目|説明|
|-|-|
|長さ|クリップの表示時間|
|スピード|再生速度（0.1〜10倍）。端ドラッグ+Shiftでタイムリマップも可|

#### ④ 移動 / 回転 / 拡縮 / 透明度（KF対応）

各プロパティのラベルを左右にドラッグすると数値をスクラブ変更できます（ドラッグ速度で変化量が変わります）。  
各プロパティの右に **◇KFボタン** があります。

|項目|タイムライン色|説明|
|-|-|-|
|移動 X/Y|🔴 赤|水平・垂直位置。プレビューでもドラッグ可。ラベルドラッグでスクラブ|
|回転|🔵 青|回転角度（°）。上下ボタンは1°単位、入力は0.1°まで対応|
|拡縮 X/Y|🟢 緑|X・Y個別にスケール変更可能。「拡縮」ラベルドラッグでXY等倍変更|
|透明度|🟡 黄|不透明度（0〜1）|

**KFの使い方：**

1. **◇ボタン**を押してKFを有効化（◆になる）
2. 時間を変えて数値を入力 → その時刻にKFが自動追加
3. **+ボタン**で現在時刻のKFを明示的に追加
4. KFリストの項目をクリック → その時刻にジャンプ
5. タイムライン上のダイヤ◆をドラッグ → KFの時刻を移動
6. ◆ボタンを再押し → KF無効化（現在値を保持）

**KFのデータ構造：**

* 位置: `{t, x, y}` 形式（X/Y同一KF）
* 拡縮: `{t, sx, sy}` 形式（X/Y同一KF、個別補間）
* 回転/透明度/ぼかし: `{t, v}` 形式

#### ⑤ 実サイズ表示

現在の拡縮を反映した実際のピクセルサイズが表示されます。

#### ⑥ エフェクト

|項目|タイムライン色|説明|
|-|-|-|
|ガウスぼかし|🩵 水色|ぼかし量（0〜100）、KF対応|

#### ⑦ クリップカラー

タイムライン上のクリップの表示色を変更できます。

#### プロパティのリセット

移動・回転・拡縮・透明度・ぼかし・スピード・合成モード・クリップカラーを初期値に戻し、全KFも削除します。

## 簡易モード

ツールバー右端の **「通常」** ボタンをクリックすると簡易モードに切り替わります。

**簡易モードで表示されるもの：**

* ツールバー（全機能）
* プレビュー倍率バー（Fit/25%/50%/100%）
* プレビュー
* タイムライン（ルーラーのみ、クリップ行・レイヤー名は非表示）
* ルーラー右端に「ズーム」ボタン

**簡易モードで非表示になるもの：**

* 素材パネル
* プロパティパネル
* コンポタブ
* タイムラインヘッダー（+映像・+音声・ズームスライダー）
* レイヤー名列

ペン・コマ送り・ショートカットなど全機能はそのまま動作します。  
**「簡易」** ボタンをクリックすると通常モードに戻ります。

## ペンツール

1. ツールバーの **✏ ペンボタン** でON（プレビュー背景が赤くなる）
2. プレビュー上でドラッグして描画
3. **右ドラッグ** → 消しゴム（範囲を消去）
4. 描いた内容は現在フレームの「ペン Xf」という素材として素材パネルに追加される
5. 素材パネルで「ペン Xf」をクリック → プロパティの **「PNG書き出し」** ボタンで単独保存可能
6. **💾 収集保存** で他の素材と一緒にまとめて保存

> ⚠️ 通常の💾保存ではペン素材はJSONに内包されますが、ファイルとしては存在しません。「収集保存」または「PNG書き出し」で明示的に保存してください。

## テキストレイヤー

1. ツールバーの **T+ボタン** → 作成ダイアログが開く
2. テキスト内容・フォントサイズ・色・フォント・整列・太字/斜体・縁取りを設定
3. 「作成」→ アクティブなコンポの先頭レイヤーに5秒のテキストクリップが配置される
4. クリップを選択 → プロパティパネルでテキストや書式を後から変更可能
5. KF（移動・回転・拡縮・透明度）も通常クリップと同様に設定できる

|AEmini|After Effects|
|-|-|
|サンセリフ|Arial|
|セリフ|Times New Roman|
|等幅|Courier New|
|ゴシック体|ヒラギノ角ゴ / 游ゴシック|
|明朝体|ヒラギノ明朝 / MS明朝|

## 書き出し

### MP4書き出し

* コンポのプロパティ → 「▤ MP4書き出し」ボタン
* ビットレートを選んで書き出し（4/8/16/30 Mbps）
* 音声トラックがある場合はAAC音声も含む
* **Chrome 94以降 + WebCodecs対応が必要**

### 連番書き出し

* コンポのプロパティ → 「▤ 連番書き出し」ボタン
* PNG・JPG・BMPを選んでフォルダに出力
* フォルダ選択ダイアログが開く（File System Access API対応ブラウザ必須）

## プロジェクトの保存と読み込み

### 📂 読込

保存したJSONを読み込みます。素材ファイルが元の場所にある場合は自動復元。  
見つからない素材は「⚠ リンク切れ」として表示され、「リンク」ボタンで再指定できます。

### 💾 保存

JSONファイルとして保存。テキスト素材・ペン素材はJSONに内包されます。  
通常の素材（画像・動画・音声）は**パスを記録するだけ**でファイルはコピーされません。

### 💾 収集保存

JSONと全素材ファイルを選択したフォルダにまとめてコピーします。  
別PCで開く場合や素材を整理したい場合に使用。

## After Effectsとの連携（Mini2AE.jsx）

AEのスクリプトメニューから `Mini2AE.jsx` を実行。

### Import（AEmini JSON → AE）

1. 「素材フォルダ」に素材が入っているフォルダを指定
2. 「読み込み」ボタンを押してJSONファイルを選択
3. コンポ・レイヤー・素材・フォルダ構造が再現される

**対応内容：**

* 映像/音声クリップの配置・タイミング・速度
* 移動・回転・拡縮・透明度（静的値 + KFアニメーション）
* テキストレイヤー（フォント・サイズ・色・縁取り）
* 平面レイヤー
* ガウスぼかしエフェクト
* フォルダ構造
* 素材が見つからない場合はグレー平面で代用（名前に\[不明]付加）

### Export（AE → AEmini JSON）

1. AEでコンポを開いた状態でスクリプトを実行
2. 「対象」を選んで「書き出し」ボタン
3. JSONファイルを保存

**対応内容：**

* レイヤーの配置・タイミング
* 移動・回転・スケール・不透明度（KFも含む）
* テキストレイヤーの内容・書式
* フォルダ構造・平面レイヤー

\---

## 注意事項・制限

* **Chrome推奨**（File System Access API使用のため）
* MP4書き出しは Chrome 94以降 / WebCodecs対応が必要
* 音声プレビューは再生時のみ（シーク精度に限界あり）
* 連番画像の最大フレーム数はメモリに依存
* ペン素材は通常保存ではJSONに内包、ファイルとしては収集保存が必要
* ブラウザをリロードすると再生位置・選択状態はリセットされる（プロジェクトデータは保存済みであれば保持）
